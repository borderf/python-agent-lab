# 学习导航：一条项目主线，三个学习方向

先把订单数据变成可运行程序，再把程序变成可靠服务，随后完成 **DocPilot：找到适用原文并回答**。需要受保护动作时，再实现 **ProcureAgent：审查、批准与恢复**。架构学习研究这套系统为什么这样组织、怎样验证；产品学习研究谁需要它、怎样设计、交付与验证采用。

学习进度只按各册章号记录。每章完成一项累计任务；例子编号、旧周编号和项目版本仅供查找。下列入口各有用途，不再同时执行多份周计划。

## 按一个成果继续，而不是按多套编号跳转

| 累计成果 | 主读章节 | 通过后留下什么 |
| --- | --- | --- |
| 订单程序 | Python 1–12 | 新数据可运行、金额与冲突明确、文件入口与检查可复现 |
| 可靠服务 | Python 13–17 | 输入、身份、外部错误、状态与恢复边界 |
| DocPilot | Python 18–23 | 自己的核心通过20步契约，再接HTTP、真实模型与逐题评测 |
| ProcureAgent | Python 24–26 | 受限工具、批准绑定载荷、失回执恢复与效果核对 |
| 作品解释 | Python 29–30 | 一次失败修复、一项取舍、一次陌生条件演示 |

Python 27–28是按需选修：先有跨进程工具或分工问题，再评估MCP与多Agent。DocPilot完成后即可收集AI应用岗位反馈；不必等全部选修完成。

## 架构与产品分别怎样学

**架构：** 按[架构第1–14章](architecture-book/教材目录.md)独立推进，沿任务→约束→模块→契约→数据→协作→容量→恢复→安全→发布→选型→评审。每章更新同一份架构记录，最终形成一个可复查的决策与实验索引。能开发后端服务即可开始，不要求先读产品教材。

**产品与创业：** 按[产品第1–14章](product-founder-book/教材目录.md)沿问题→访谈→定位→规格→交互→全栈切片→指标→实验→AI复核→定价→渠道→运行→资源决定推进。产品型工程师先完成任务与交付，创业再深入购买、成本和资源承诺。不要求先读架构全册。

首次学习以**Python 为主线**；架构与产品是按需旁线，做完 DocPilot 后再按当前问题各选几章。若目标偏架构或产品，可先读对应册，但仍用同一组订单与 DocPilot 材料练习。Agent 方向在第24章 4.2 用 12 步契约实现工具循环，第26章再组合审批与恢复。

**AI 基础原理（配套）：** 做第18章模型调用或第20–22章 RAG/评测前，按[AI 基础原理](ai-foundations/教材目录.md)读第1–8章：tokenizer、embedding、Transformer、训练、推理、幻觉/RAG、评测。它解释“为什么”，Python 第18–22章负责“怎么落地”；面试前用附录A自测。

**TypeScript 与 AI 交付（选修）：** 按[TypeScript 教程](typescript-book/教材目录.md)读全书 18 章，学类型边界、运行时校验、异步取消、SSE、模块工程化、React 数据流、异步缓存、流式界面、Hono BFF、SQL/Drizzle、认证/多租户、AI 工具调用、测试、观测与部署。它不替代 Python 后端主线；适合要交付 DocPilot 控制台、流式界面或全栈作品时并行学习。

## 每章怎样真正学会

1. 用一句话复述上一章留下的程序或决定，以及当前遇到的新问题。
2. 先读原因和完整推演，画数据、执行或用户路径，能解释后再运行。
3. 合上参考，完成本章累计任务；专题练习只用于补当前卡点。
4. 用一组新输入或新约束验收，记录失败的首个环节与修复；下一章沿用该成果。

自动检查不是全能评分。订单TODO检查你的订单实现；[学习者契约](../tests/learner/练习说明.md)检查指定模块；仓库默认测试主要保护参考代码；文档脚本检查结构与链接。用户是否完成任务、架构选择是否适合约束，还要观察或实验。

## 两种投入范围

以下是规划情景，尚不是学习者实测承诺；按有后端经验、每周8–10小时估算，前两周记录实际用时后修订。

| 范围 | 内容取舍 | 初始预算 |
| --- | --- | --- |
| 精简交付 | 语言按自测补缺；完成订单、DocPilot、HTTP、真实调用、评测与一次部署；架构和产品只做当前决定；暂缓Agent与扩展 | 约150–200小时，约4–6个月 |
| 完整学习 | 完成Python主线与受控Agent，两册进阶逐章任务、恢复与发布演练、产品试点与反例迁移 | 约350–600小时，约9–18个月 |

真实客户招募、采购与服务等待另外记录，不假设按编程排期完成。职业竞争力来自能解释、能独立交付、能验证与改进，教材不能承诺固定时长上岗。

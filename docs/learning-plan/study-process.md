# Python → AI Agent：8 周学习过程

本文件保留为基础阶段的展开日程。长期项目执行以 [16 周 DocPilot / ProcureAgent 主线](enterprise-ai-16-weeks.md) 为准；Python 基础验收有缺口时使用本日程补齐，不同时执行两套周计划。[20 课教程](../tutorial/README.md) 提供原理、起始代码和检查。

## 目标与节奏

目标是能够独立完成一个有类型、有校验、有测试的 Python 程序，把它封装成服务，再接入模型、工具和简单文档检索。

适合有 Java 后端经验的你。按每次 90–120 分钟、每周 5 次学习加 1 次验收安排，另一天休息或补欠账。8 周是参考；验收没通过就顺延。基础阶段自测全部通过后可以压缩，约 6 周走完第一轮；不要通过删掉测试和异常练习来赶时间。

一个项目贯穿全部阶段：

```text
订单 JSON → 订单报告 CLI → 有校验和测试的工程
         → HTTP/异步数据客户端 → FastAPI 服务
         → 模型分析说明 → 订单工具助手 → 订单与政策问答助手
```

## 先确认自己的起点

每项都要给出自己的代码和运行结果，而不是只判断“看懂了”。

- [ ] 能解释列表引用、浅复制与深复制；写出一个可变默认参数的错误及修复。
- [ ] 能独立用字典、列表和集合完成筛选、分组与 ID 去重。
- [ ] 能区分返回值与 print，并解释生成器被消费后的行为。
- [ ] 金额已经改为整数分，样例、排序、汇总和测试字段一致。
- [ ] 能从 JSON 读取、校验、去重、生成报告，处理空数据和错误文件。
- [ ] 核心业务有正常及重要边界测试。

目前仓库原有集合模块仍以 float 保存金额，测试案例较少，因此建议先自查前 3 项，再从第 1 周第 4 次学习的整数分任务继续。新练习区的 TODO 是你要完成的练习，不能当作已经完成的能力。

## 每次学习的固定流程

1. 10 分钟：复述上次代码的输入、输出和一个边界。
2. 20–25 分钟：只读今天相关章节，写下与 Java 不同的机制。
3. 45–60 分钟：独立实现项目任务，先尝试再查资料。
4. 15 分钟：运行检查，分析一个失败原因，记录进度。
5. 有余力时：合上资料重写关键函数，完成一次范围清楚的 Git 提交。

使用 AI 时，先提供自己的尝试和具体报错，优先请求解释、提示和评审。可以让 AI 检查代码，再用测试和官方文档核对结论；能独立重写才算学会。每周验收日把未完成项带到下周，避免积累多个半成品。

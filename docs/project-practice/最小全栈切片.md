## 0. 先做更小的 B+ 页面

在进入本切片前，先做一个不依赖 React、认证和数据库的页面：

```text
输入订单金额 → 点击提交 → POST /api/preview → 页面显示计算结果
```

只验证四件事：表单提交、HTTP JSON、DOM 渲染、加载/错误状态。它属于学习导航的 B+ 阶段；跑通后再进入下面的搜索切片。不要一开始同时补 React、BFF、认证和 RAG。

## 1. 这一片要证明什么

```text
浏览器输入问题 → BFF 转发 → Python 检索服务 → 返回来源 → 页面打开原文
```

只证明四件事：

1. 页面能把查询送到 BFF；
2. BFF 能带上可信身份转发，不让浏览器伪造 tenant；
3. Python 返回稳定结构，空结果/越权/上游失败可区分；
4. 浏览器能从结果打开来源原文。

不在这一片做：真实模型生成、SSE 流式、完整认证系统、审批、写入、Docker 生产部署。它们接在同一条链上逐步增加。

## 2. 固定契约

```http
POST /api/search
Content-Type: application/json

{ "query": "预付款上限", "asOf": "2026-07-01" }
```

成功：

```json
{
  "results": [
    {
      "sourceId": "policy-a",
      "title": "预付款制度 v2",
      "version": "2",
      "quote": "预付款比例不得超过合同金额的20%。",
      "url": "/sources/policy-a?version=2"
    }
  ]
}
```

失败：

| 情况 | 状态 | 页面行为 |
| --- | --- | --- |
| 空查询/非法日期 | 422 | 表单旁显示字段错误 |
| 没有可见证据 | 200 + `results: []` | 明确“没有找到可引用来源”，不伪造答案 |
| 身份缺失/越权 | 401/403/404 | 统一错误，不泄漏资源是否存在 |
| Python 不可用 | 503 | 显示“检索暂不可用”，保留重试 |
| 上游超时 | 504 | 可重试提示，不返回空列表冒充成功 |

**开发期身份：** 只允许 BFF 从服务端配置读取固定 tenant，例如 `DEV_TENANT=a`；不接受浏览器传 `tenant_id`。页面和日志中标注“开发身份，不是生产认证”。

## 3. 实施顺序

### 第 1 步：Python 返回稳定 JSON

- 复用 DocPilot 的可信租户、日期过滤、检索与来源结构；
- 用固定数据测试正常、空结果、跨租户、日期边界；
- 先不接模型，不生成自然语言答案。

验收：`curl`/HTTP 测试能拿到稳定 `results`，错误码可区分。

### 第 2 步：BFF 只做转发与身份

- `POST /api/search` 接收 `{query, asOf}`；
- 从服务端配置或会话取得 tenant；
- 转发到 `DOCPILOT_URL`，超时/错误映射为上面的失败表；
- 不复制检索规则，不在 BFF 重新算金额或权限。

验收：浏览器传 `tenant_id=b` 不生效；BFF 日志不打印密钥。

### 第 3 步：最小页面

- 一个查询框、一个业务日期、一个提交按钮；
- 用 `textContent` 渲染标题/引文，不拼 `innerHTML`；
- 结果为空、加载中、错误、无权限分别有文案；
- 来源链接可打开 `/sources/:sourceId?version=...`。

验收：键盘可提交；空结果不显示空白页；错误不伪装成“没有结果”。

### 第 4 步：浏览器验收

Playwright 至少覆盖：

1. 输入“预付款上限” + 日期，显示一条结果和来源链接；
2. 返回空列表，显示“没有可引用来源”；
3. 返回 503，显示可重试错误；
4. BFF 收到浏览器伪造的 `tenant_id`，仍使用开发 tenant；
5. 点击来源，打开对应版本页面。

先用 `page.route("**/api/search", ...)` 固定响应，再跑一次真实 Python + BFF 的冒烟。

## 4. 目录与责任

```text
apps/web/          页面、表单、结果与来源链接
apps/server/       BFF：/api/search 转发、身份、错误映射
python 服务        DocPilot 检索与来源（已有参考实现）
tests/e2e/         Playwright 验收
```

BFF 不拥有检索规则；Python 不信任浏览器传来的 tenant；页面不直接访问 Python 内部地址。

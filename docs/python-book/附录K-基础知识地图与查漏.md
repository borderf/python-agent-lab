## 初读：先操作，再归纳，再解释实现

第1章先能运行脚本、辨认基本值、赋值与比较，再写条件和循环。第2章处理数字、文本和字节，第3章处理多份记录。函数、异常、类、模块与项目工具随后逐步接入。进程、堆、栈的详细推演保存在第1章3.5，读过具体操作后回看。

一节的学习动作依次为：运行一个最小例子；对照输出解释每行；改变一个输入；归纳规则；最后检查一个边界。代码中的assert用于核对学习例子，实际输入验证按相应业务与异常章节实现。

## 常用内置操作按任务认识

查看类型用type，严格类型边界与继承关系在第2、6、9章区分；查看长度用len；转换按int、float、str等各自的输入契约进行。处理多个元素时再学range、enumerate、zip、sorted、sum、min与max，回到第3、8章完成一次实际计算。每用一个新操作，都查清输入、输出、是否修改原对象以及失败条件。

后续遇到GUI、XML、邮件或其他数据库时，可按具体项目扩展。完成当前主线以订单工具、DocPilot和ProcureAgent的独立交付为依据，专题数量不代替掌握证据。

从文本取得数量，转换后与单价计算；把两笔订单放进列表，按ID组织字典，标记见过的ID；给出汇总、空输入和重复冲突的处理。先手算，再运行，最后分别说明类型、引用、比较、控制流和失败发生的位置。详细验收见[阶段自测](附录H-阶段自测与复习.md)。

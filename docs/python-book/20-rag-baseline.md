## 1. 学习目标与前置知识

## 2. 基础知识讲解

RAG 包含离线解析/分块/向量化/索引和在线查询/检索/生成。分块大小、重叠、标题和来源元数据影响能否召回足够上下文，不能只以字符数拍定最佳参数。

Embedding 维度、归一化和距离度量要与模型及索引一致。向量相似是相关性的线索，不保证事实、权限或时效。Qdrant Collection、Point、Payload 等承载向量和过滤信息。

tenant、文档权限、版本、生效区间在所有检索路径中一致应用，授权依据来自服务端。索引更新使用稳定ID和版本策略，避免重复与过期材料混用；删除也要考虑缓存和派生索引。

## 3. 原理讲解与推导

检索是否找到证据与生成是否忠于证据是两个可分离问题。先建立关键词与向量基线，再对单个变量做实验。

### 项目化展开

#### 检索管道

```text
解析 → 规范化来源/版本/权限 → 分块 → 向量化 → 索引
查询 → 确定用户可见范围/业务日期 → 过滤检索 → 可选融合/重排 → 证据回答
```

每个片段保存 source_id、版本、chunk_id、租户、授权范围、生效区间与来源位置。更换 embedding 的维度/模型时创建可区分的新索引配置，不混入旧向量；重复入库要有稳定标识和更新策略。

Dense、稀疏和重排的候选都必须经过相同权限与版本约束；工具输出与提示词也不能泄露不可见材料。空召回、来源冲突、来源过期分别处理。

### 检索的数学与索引选择

余弦相似度为 `dot(x,y)/(||x|| ||y||)`，零向量要有明确策略。单位归一化向量的点积与余弦排序相同；未经归一化时不能任意替换距离。近邻索引常用近似方法用召回换时间/空间，应以标注集和负载评估。

分块ID要能追溯来源和版本；索引记录embedding模型、维度、预处理与分块版本。过滤不是回答后删词，而是决定哪些内容能进入检索候选和提示。更新/删除需同步派生索引和缓存。

## 4. 示例与逐步走查

### 余弦与过滤小实验

```python
# book-example: B20
from math import sqrt
def cosine(left, right):
    denominator = sqrt(sum(x*x for x in left))*sqrt(sum(y*y for y in right))
    if not denominator:
        raise ValueError("zero vector")
    return sum(x*y for x,y in zip(left,right))/denominator
rows = [{"id":"A","tenant":"a","vector":[1,0]}, {"id":"B","tenant":"b","vector":[1,0]}]
visible = [row for row in rows if row["tenant"] == "a"]
ranked = sorted(visible, key=lambda row: cosine([1,0],row["vector"]), reverse=True)
assert [row["id"] for row in ranked] == ["A"]
```

手工向量只说明评分与权限顺序；真实实验还需维度一致校验、真实embedding、索引参数和业务标签。

## 1. 学习目标与前置知识

验证系统事实、权限和失败恢复，持续回归。前置：第17、21–25章。

## 2. 基础知识讲解

离线逻辑测试、真实模型评测和线上观测提供不同证据。固定集包括正常、无答案、旧版本、越权、工具故障、坏输出、审批拒绝和子任务超时；人工标签与模型辅助评价分开。

提示注入来自不可信文档/工具结果，不能让其指令提高权限或覆盖应用规则。只读/写入工具分离，身份、参数、审批与执行点授权由程序完成。

Trace 连接模型、检索、工具和动作；日志采集前脱敏。费用优先使用实际可获得数据，缺少账单时记录token、调用数和硬件时间，不编造金额。缓存和降级要保留权限与版本语义。

## 3. 原理讲解与推导

可验证的事实与动作是质量核心，不只是语言流畅或模型评审得分。逐项记录失败类别，关键越权不能被平均分掩盖。

### 项目化展开

### Agent 与审查指标

| 指标 | 记录方法 |
| --- | --- |
| 任务完成率 | 按人工定义的任务结果判定完成数/总任务数；partial 单列 |
| 风险召回 | 命中人工标签风险条目数/应识别风险条目数 |
| 风险精确率 | 命中人工标签风险条目数/输出风险条目数；资料不足单列 |
| 工具正确性 | 工具是否正确选择、参数是否正确、是否执行并回传 |
| 引用与事实 | 原文/规则是否支持结论，金额是否与确定性计算一致 |
| 成本 | 相同计价口径的实际可获得费用；否则记录输入/输出 token、调用数和硬件时间 |
| 延迟 | 相同环境记录每任务耗时、p50/p95、样本数；冷启动单列 |
| 失败 | 网络、解析、检索、权限、预算、模型结构、逻辑、审批等类别 |

零分母指标记 N/A 并说明样本条件，不编成 100%。用重复运行观察模型波动，不用少数样本的 p95 宣称稳定性能。模型评审可以辅助分析，关键风险与证据标准由人工核对。

### 必做故障矩阵

| 场景 | 必须观察到的行为 |
| --- | --- |
| 空/损坏/不支持文档 | 明确状态，不制造字段/引用 |
| 数字或 JSON 格式错误 | 校验失败，不触发后续业务动作 |
| 旧版本政策与当前政策并存 | 按业务日期选择，无法消除冲突则要求复核 |
| 另一租户数据 | 服务端拒绝或过滤，模型看不到不可访问来源 |
| 文档中的恶意指令 | 当作不可信文档内容，不提升权限或执行指令 |
| 工具/模型超时 | 分类记录，限制重试，任务及连接清理 |
| 子 Agent 超时 | partial/needs_review，说明缺失部分 |
| checkpoint 后重启 | 正确映射任务与身份并恢复，外部动作可对账 |
| 重复提交/重复 resume | 幂等记录可核对，模拟业务效果不重复 |
| 审批拒绝或载荷变更 | 不执行；旧审批不能用于新载荷 |
| trace 输出 | 可以追踪但不泄露凭据、敏感原文和越权数据 |

### 每周记录模板

```text
里程碑：Wxx
问题：上一版有哪些具体失败？
改动：本次加入什么，为什么需要？
复现：命令、依赖锁、代码/数据/模型/提示版本。
验证：自动测试结果、固定评测样本数、人工核对。
比较：基线与本版的质量、耗时、用量和失败类别。
代价：新增依赖、硬件要求、维护与恢复复杂度。
结论：采用/保留实验/回退，依据是什么？
下一步：未完成任务和当前限制。
```

### 评测指标和人工标签

任务完成率、风险召回、精确率、引用支持性、无答案处理、延迟与用量应分开。零分母记N/A并解释；模型评审不能替代关键权限与业务动作的确定性检查。

样本划分避免全部参与调参；保留不同文档版本、困难问题与失败注入。记录模型、提示、工具Schema、数据和索引版本，才能解释“同一问题这次变差了”。

## 4. 示例与逐步走查

### 指标计算小实验

```python
# book-example: B26
def recall_at_k(retrieved, relevant, k):
    if not relevant:
        return None
    unique = list(dict.fromkeys(retrieved))[:k]
    return len(set(unique) & set(relevant))/len(set(relevant))
assert recall_at_k(["A","A","B"], {"A","C"}, 2) == 0.5
assert recall_at_k([], set(), 5) is None
```

本例按唯一来源计数，不与chunk级结果混用。无答案/越权另统计；高Recall也不证明答案忠于引用或风险规则正确。

## 6. 验收与自测

**行为验收：** 指标分母、样本、版本和环境明确；无证据不编造；越权和未经审批动作被阻断；预算可执行。

**原理验收：** 合上资料解释本章一个机制，预测一个反例，说明规则属于语言语义、库约定还是实现观察。

**提交证据：** 实现位置、运行命令、正常案例、至少一个错误/边界案例、一次失败原因和修复记录。自动检查只证明其覆盖行为；未实现任务不因示例通过而算完成。

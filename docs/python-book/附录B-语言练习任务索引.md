## 每课增加的原理任务

除原有动手任务，每课还要回答：规则是什么、状态怎样变化、为什么当前实验会得到该结果、改变一个条件会怎样、项目中如何应用。记录自己的预测与实际结果，不能仅运行讲义后将断言通过记为掌握。读不懂的原理可拆成额外学习次数，日程随实际理解进度顺延。

## 主题1：解释器、对象、表达式、文本和数字

主读：[官方教程第 2–3 章](https://docs.python.org/zh-cn/3.12/tutorial/)。参考：[对象模型](https://docs.python.org/zh-cn/3.12/reference/datamodel.html)。本项目先以 Python 3.12 语法为基线，解释器版本用实际运行结果确认。

理解：名称绑定对象；相等与相同不同；类型属于对象；重新赋值与原地修改不同。对象可变性、真假值与短路决定许多看似奇怪的行为。

| 课次 | 学习内容 | 独立练习与验收 |
| --- | --- | --- |
| P01 | 解释器/脚本/模块、工作目录、print 与返回值、读 traceback | 运行当前模块，制造再定位 NameError/TypeError；记录解释器路径、版本和报错行 |
| P02 | 名称、id、type、is/==、可变对象、引用/浅/深复制 | 做 L01；预测后运行；解释 `a=[[]]; b=a.copy()` 为什么仍共享内部列表 |
| P03 | bool/None、and/or/not、比较链、if/elif、for/while、break/continue、循环 else | 做 L02；覆盖 0、False、None、空字符串；再选读 match 与赋值表达式，不急着套入所有分支 |
| P04 | int/float/Decimal、/与//、负数取余、round、单位与格式化 | 做 L04；已有 format_cents 需覆盖 0、1、True、负数；解释显示两位小数与精确计算的差别 |
| P05 | str/bytes、Unicode、UTF-8、切片、strip/split/join、f-string | 做 L03；中文编码往返；理解字节长度和字符长度，不能混用 str/bytes |

第 6 次验收：合上资料解释对象实验，为已有两个基础函数增加有效反例。不要依赖整数缓存或字符串驻留去判断值相等；None 使用身份判断。

交付：`基础语言实验记录 + 基础函数测试`。

## 主题2：容器、数据转换与算法表达

主读：[数据结构](https://docs.python.org/zh-cn/3.12/tutorial/datastructures.html)。参考 collections 标准库。

理解：list 保存顺序，dict 映射键值，set 保存唯一可哈希元素，tuple 固定引用序列。tuple 内部可以引用可变对象；“不可变容器”不等于内部一切不可变。

| 课次 | 学习内容 | 独立练习与验收 |
| --- | --- | --- |
| P06 | list/tuple、索引/切片、解包、嵌套对象、追加/扩展 | L05：规范化订单字段；比较 append/extend，检查输入不变 |
| P07 | dict 的键、in/get/items、缺失值、插入顺序、可哈希性 | 为相同用户分组；区分字段不存在与字段值为 None；说明列表为什么不能直接当键 |
| P08 | set/frozenset、并交差/子集、去重、dict/set 的相等与哈希约束 | L06：保持首见顺序并识别同 ID 冲突；集合本身不能提供原始顺序 |
| P09 | 推导式、enumerate/zip、any/all、排序 key、稳定排序 | 同金额的 A/B 保持相对顺序；检查空集合下 all/any；不在遍历中随意删原列表 |
| P10 | Counter/defaultdict/deque、复杂度与数据结构选择 | 做订单状态计数、最近 N 条错误队列；用一次遍历完成分组，而不是每组再扫描全量 |

验收：订单筛选、汇总、分组、稳定排序、重复与冲突处理，正常和空输入都有测试。能解释 list 成员查找与哈希表查找的一般代价差异，不把平均复杂度当成绝对保证。

交付：`订单纯函数模块`，复用现有 collections 练习。

## 主题3：函数、作用域、闭包与装饰器

主读：[定义函数及参数](https://docs.python.org/zh-cn/3.12/tutorial/controlflow.html#defining-functions)、[作用域](https://docs.python.org/zh-cn/3.12/tutorial/classes.html#python-scopes-and-namespaces)。

理解：函数是一等对象；调用时名称绑定到传入对象；默认参数在定义时求值。自由变量查找时机影响闭包，global/nonlocal 指定赋值绑定的位置。

| 课次 | 学习内容 | 独立练习与验收 |
| --- | --- | --- |
| P11 | return/None、参数传递、纯函数与副作用、默认参数 | L07：修复默认列表跨调用共享；说明重绑定参数为何不改变调用方名称 |
| P12 | 位置/关键字、/与*、*args/**kwargs、解包、签名 | 为工具调用写明确签名；多参数/缺参数错误能够解释；不要把所有接口都写成 **kwargs |
| P13 | LEGB、局部变量、global/nonlocal、闭包晚绑定 | L08：三个倍率函数应分别乘 1/2/3；解释错误版为什么全乘 3 |
| P14 | 高阶函数、lambda、partial、sorted key | 写可组合的订单筛选；用命名函数表达复杂规则，比较 lambda 的适用范围 |
| P15 | 装饰器、wraps、带参装饰器、叠加顺序 | L09：记录调用但保持返回值/异常/元信息；比较 `@a @b` 的调用嵌套 |

验收：做一个同步函数注册表，先普通 register，再加装饰器；未知名称与重复注册有明确错误。不会执行模型或用户提供的任意表达式。

交付：`同步 ToolRegistry 小模块`，此时可用手工校验，运行时模型在 W08 补齐。

## 主题4：迭代、生成器、异常与资源生命周期

主读：[迭代器与生成器](https://docs.python.org/zh-cn/3.12/tutorial/classes.html#iterators)、[异常](https://docs.python.org/zh-cn/3.12/tutorial/errors.html)、contextlib。

验收：逐行读取、逐条校验的处理器，正常、坏行、提前退出都能解释。send/throw 和复杂异步生成器先作为扩展，不要求本周深入。

| P55 | perf_counter、timeit、cProfile、tracemalloc、缓存 | L24 性能部分：先核对结果，再测耗时/峰值内存；缓存说明失效和空间代价 |

验收：为至少两种任务解释选择同步、异步、线程或进程的依据。性能报告包含数据规模、运行环境和多次测量，不能用一次小样本宣布某写法永远更快。

交付：`并发选型与性能实验报告`。

## 什么时候进入 AI 项目

优先完成 G1/G2/G3 和 P56–60。已有扎实基础且希望并行试用时，可以在 G2 后体验一次模型调用，但不要据此跳过异步与资源管理。完成语言与工程章节后，按教材第18章起及项目里程碑继续；框架变化再查当前官方文档。

## 每次学习如何执行

1. 10 分钟：不看资料回答上次的两个问题，预测一个输出。
2. 20–25 分钟：阅读教材对应章节，按需查官方资料，写出与 Java 不同的机制。
3. 45–60 分钟：独立完成当前任务，至少尝试 15 分钟再看提示。
4. 15–20 分钟：运行检查、增加反例、记录错误原因与下次任务。

每个知识点留下四样证据：自己的解释、小实验、实际函数/模块、反例与验收。无法解释的通过结果记为待复习，不算完全掌握。

这张表用于检查“学过什么、能做到什么、还欠哪一层证据”。不能因为正文出现某个名词，就把它当作已经讲透或自己已经掌握。以对应案例、练习和迁移问题验收。

## 五、这本书的范围与后续深度

### 从覆盖检查到独立掌握

语言卷已覆盖 Python 3.12 项目开发的主要语言机制、标准库、类型、测试、并发和资源边界。是否掌握用[阶段自测](附录H-阶段自测与复习.md)中的陌生输入、独立重写和一周后复验判断；读完或通过原样例只能作为其中一项证据。

工程学习接上[项目装配手册](../project-practice/从实验到项目交付.md)：按 web、agent、vector、mcp 等可选依赖组实际运行 SQLAlchemy/Alembic、FastAPI、LangGraph、Qdrant 与 MCP。数据导入、接口、引用和反馈形成同一条切片，再逐层替换真实模型、向量和部署环境。

AI 原理增加[小矩阵、复杂任务与上下文对照](附录I-AI原理与复杂任务实验.md)，架构增加[并发、排队和迁移实测](../architecture-book/附录E-实测案例与推导.md)，产品增加[试点、拒绝与销售练习](../product-founder-book/附录G-试点案例与销售练习.md)。按[岗位对照](附录J-岗位对照与工程协作.md)决定继续深入的方向，并保留原始实验和真实反馈。

主线面向Python/AI应用工程转型，覆盖从语言到可靠应用的连续链路。CPython内部实现、元类与C扩展、完整深度学习数学、PyTorch训练、GPU内核、多模态训练、检索模型训练、分布式数据库与集群运维仍是独立专题。主线中说明它们与当前问题的关系，专题能力需要自己的实验与教材。

学习时先确认自己是“看见名词、理解机制、独立实现、完成真实集成”中的哪一层。未安装依赖、未启动服务、未做故障演练的部分保留为待验证，不用离线例子通过替代它们。

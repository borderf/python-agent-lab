# 知识覆盖与阅读层次

[全书目录](教材目录.md) · [导读](00-导读与学习方法.md)

这张表用于检查“学过什么、能做到什么、还欠哪一层证据”。不能因为正文出现某个名词，就把它当作已经讲透或自己已经掌握。以对应案例、练习和迁移问题验收。

**主线必修**要求能解释、运行、修改并通过本章验收。**原理入门**提供机制与适用条件，尚不等于具备该方向完整工程经验。**专题延伸**需要目标岗位、数据、环境和单独实验，不阻塞应用开发主线。

这些内容补进原章节，并继续使用订单、DocPilot与ProcureAgent，阅读顺序不另增分支。先掌握最小例子，再做补强练习，最后接真实后端；内存模拟和手工向量仍不能替代持久化、真实embedding与模型集成证据。

第1–3章运行代码不要求先会def、class或lambda。E01动态编译观察移至第7章，E02的复制加异常实验移至第5章，E03回调短路移至第4章，E06自定义哈希键移至第6章。JSONL完整题L12移至第7章，装饰器异常包装在异常章回看。编号用于索引，不是学习顺序。

每章先读情境和基础案例，做一次小修改，再看机制实验；最后完成练习和可展开的参考推导。第4部分的短例子用于回看机制，不替代第2部分的完整讲解。

## 五、这本书的范围与后续深度

主线面向Python/AI应用工程转型，覆盖从语言到可靠应用的连续链路。CPython内部实现、元类与C扩展、完整深度学习数学、PyTorch训练、GPU内核、多模态训练、检索模型训练、分布式数据库与集群运维仍是独立专题。主线中说明它们与当前问题的关系，专题能力需要自己的实验与教材。

学习时先确认自己是“看见名词、理解机制、独立实现、完成真实集成”中的哪一层。未安装依赖、未启动服务、未做故障演练的部分保留为待验证，不用离线例子通过替代它们。

## 2. 基础知识讲解

### 2.1 根据数值含义选择表示

int表示整数，适合数量、索引和整数分；float适合近似计算。Python整数没有固定32位上限，但更大的整数仍消耗内存与计算资源。bool是单独的逻辑类型，同时是int的子类，因此金额入口不能只靠isinstance(value, int)排除True。

加减乘和幂使用`+ - * **`。`/`执行真除法，`//`向下取整，`%`给余数。对于整数a和非零b，商余满足`a == (a // b) * b + a % b`。负数整除不是简单去掉小数部分，先用纸算再验证。

#### 案例推进：精度问题应该在哪一层解决

```python
# study-example: S02B
from decimal import Decimal, ROUND_HALF_UP
assert 0.1 + 0.2 != 0.3
exact = Decimal("0.1") + Decimal("0.2")
assert exact == Decimal("0.3")
rounded = Decimal("1.005").quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
assert rounded == Decimal("1.01")
```

from/import先理解为“从标准库取得需要的工具”，模块机制在第七章展开。十进制的0.1通常无法被有限二进制小数精确表示，float保存邻近值，因此误差来自表示与运算，不是print偷偷改了结果。

Decimal从文本创建可以保留十进制输入含义；从已有float创建，则接收的已经是那个近似值。quantize用于按指定指数与舍入规则产生结果。ROUND_HALF_UP是本例选择，实际业务也可能采用其他规则，尤其要约定负数、分摊余数与逐笔/汇总舍入的时机。

#### 负数、近似比较与特殊浮点值

`/`是真除法，`//`向下取整，`%`与它共同满足整数商余关系。例如-7//3为-3，余数为2，因为-7=(-3)*3+2；它不同于简单截去小数。幂用**，不能照搬其他语言把^当乘方，^是按位异或。

```python
# study-example: S02E
import math
assert (-7 // 3, -7 % 3) == (-3, 2)
assert math.isclose(0.1 + 0.2, 0.3, rel_tol=1e-9, abs_tol=1e-12)
assert not math.isfinite(float("nan"))
assert not math.isfinite(float("inf"))
```

近似计算可以使用与需求相符的相对/绝对容差，尤其接近零时不要只靠相对容差；金额则先选正确表示。NaN有特殊比较行为，输入为float时应明确有限性与范围，不能只比较是否大于零就认为全部异常值都已处理。

### 2.2 把单位写进变量与接口

199元若以分保存，就是19900。推荐字段amount_cents，而不是依赖注释猜amount采用什么单位。汇总一直使用整数分，最后展示才拆为元与分：

```python
cents = 19901
yuan, remainder = divmod(cents, 100)
print(f"{yuan}.{remainder:02d}")  # 199.01
```

divmod同时返回商和余数；赋值中的两个名称接收两个结果，叫解包。格式`02d`要求整数至少两位、不足补零。展示格式不改变原始cents。分摊、折扣与税费另需规定舍入和余数分配。

#### 案例推进：先分开表示层，再做转换

输入原文、业务值和展示文本服务不同需求。原文用于定位错误，整数分用于计算，展示文本面向用户。转换时应写出单位，避免把1990分当成1990元。

```python
# study-example: S02A
amount_text = " 19.90 "
cleaned = amount_text.strip()
yuan_text, fraction_text = cleaned.split(".")
amount_cents = int(yuan_text) * 100 + int(fraction_text)
yuan, fraction = divmod(amount_cents, 100)
amount_label = f"{yuan}.{fraction:02d}"
assert amount_text == " 19.90 "
assert amount_cents == 1990
assert amount_label == "19.90"
```

这段是已知合法、恰好两位小数的走读，不是完整解析器。split得到两个片段，解包将它们分别绑定；int将数字文本转成整数，divmod再拆回商与余数。strip没有改变原文，说明字符串操作通常产生新值。

输入若是“19.9”，不能直接把9加成9分，而应按一位小数规则解释为90分；输入“19.999”在本书约定下拒绝。完整解析器要先检查字符、片段数和小数位数，再转换。第四章定义函数后再将这些步骤封装，不能让小例子承担它没有实现的输入保证。

### 2.3 用字符串表达和加工文本

str用单引号或双引号创建；转义序列例如`\n`表示换行。字符串不可变，strip、replace等操作返回新字符串。下标取得字符，切片`text[start:stop]`取一段，右端不包含；负下标从末尾计数。

split按规则拆成多个片段，join把一组文本合并。调用`",".join(parts)`前，应确认parts中的元素都是文本。处理用户名称可先strip两端空白，但不能默认改写大小写或内部字符，是否规范化由业务决定。

#### 案例推进：把字符串方法按任务组合起来

```python
# study-example: S02C
raw = " A-001, Alice, paid "
parts = raw.split(",")
order_id = parts[0].strip()
user = parts[1].strip()
status = parts[2].strip()
label = " | ".join((order_id, user, status))
assert label == "A-001 | Alice | paid"
assert order_id[:1] == "A" and order_id[-3:] == "001"
```

split、strip、join依次完成拆分、局部清理和重新组织。这里用到的有序容器将在第三章正式介绍，先把parts理解为一组片段。这不是通用CSV解析：字段本身含逗号或引号时，简单split会破坏结构，第七章改用csv模块。

切片右端不包含，超出范围的普通切片通常可以得到较短结果，单个越界下标却会失败。replace可以替换指定文本，startswith适合前缀判断，find返回位置或-1；不能写if text.find(...)就判断是否找到，因为位置0是假值、-1却是真值。

### 2.4 f-string把值转换成可读结果

f-string以f开头，在花括号内放表达式：`f"数量：{count}"`。冒号后是格式说明，例如`.2f`显示两位小数，`06d`显示至少6位整数。格式化用于展示，不能作为财务精度方案。

接收输入时先区分格式与数值：int("12")可以得到12，int("12.5")会失败。金额文本应先规定允许哪些写法；本书练习只接受非负ASCII数字和最多两位小数，不接受科学计数、NaN或多余小数位。

### 2.5 在文本和字节之间明确转换

磁盘、网络传输的是字节，程序处理的文本是Unicode。`text.encode("utf-8")`得到bytes；`raw.decode("utf-8")`得到str。两个边界必须采用相容编码，错误编码不应随意用ignore隐藏。汉字与组合字符说明“字符数量”与“字节长度”是两个不同要求。

#### 案例推进：从字符走到字节

```python
# study-example: S02D
text = "采购A"
raw = text.encode("utf-8")
assert len(text) == 3 and len(raw) == 7
assert raw.decode("utf-8") == text
```

编码把Unicode文本变为字节，解码按规则把字节解释回文本。相同编码往返成立，不表示任意按字节切片仍能解码。后面读取文件与HTTP内容时，继续明确当前对象是str还是bytes。

## 3. 原理讲解与推导

### 3.1 小数误差来自表示，不来自打印

有限二进制小数能精确表示某些分数，却不能精确表示所有十进制小数。float先保存近似值，再参与计算；格式化让显示更简洁，不会把存储值修成理想十进制。用整数分把业务限制到最小单位，可以避免这一类累计误差，但仍需要业务舍入规则。

### 3.2 Decimal也必须有输入和运算约定

从Decimal("0.1")开始，十进制输入的含义能够保留；从Decimal(0.1)开始，接收的已经是浮点近似。Decimal运算还受上下文精度与舍入影响。先选择单位和合法输入，再决定是否使用Decimal，不应把更换类型当成全部财务问题的答案。

### 3.3 Unicode码点与编码字节不一一对应

str长度统计码点，UTF-8为不同码点使用不同字节数；用户看见的一个字形还可能由多个码点组成。按字节截断可能把一个编码序列切断。名称规范化、长度限制和文件大小限制要分别定义。

### 4.1 沿输入到结果逐步解释

cents为12345，divmod以100为单位得到商123和余数45；f-string将两者组合为123.45。把输入改为1时，商为0、余数为1，补零后显示0.01。计算过程没有把整数分转成float，非法输入校验留到练习函数中完成。

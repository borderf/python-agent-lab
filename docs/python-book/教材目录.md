# Python、项目工程与 AI 开发实战教材

**面向有 Java 后端经验、希望转向 Python / AI 应用开发的学习者。**

本书按“运行与数据 → 调用与状态 → 程序与交付 → 可靠服务 → 模型检索与评测 → 知识问答 → 受控动作与恢复”展开，分为五卷30章。每章围绕具体问题组织基础、原因推导、执行走查和边界对照，再安排独立练习与验收。

正文先解释概念和基本用法，再通过状态变化与反例推导机制，最后连接到项目。语言卷持续使用订单数据；工程卷把订单程序变成服务；AI部分在这些边界上构建DocPilot和ProcureAgent。本册教材是Python与AI的学习主线，附录任务与里程碑用于验收对照。

每章以一个具体问题开场，在基础讲解中分步推进完整案例，代码之后解释发生了什么、为什么以及改动条件会怎样。第6部分有可展开的自测参考推导，先自己预测再查看。先从[第3章的订单筛选、分组与复制](03-容器、推导式与数据转换.md)或[第4章从函数到装饰器](04-函数、作用域、闭包与装饰器.md)可以看到这种讲法。

## 按章节累计成果

先读[导读](00-导读与学习方法.md)建立对象、执行、资源与边界模型，再按下表学习。语言练习在订单程序中累计，AI项目在第23章从空文件逐步实现。

- 新学按章号推进，专题索引只用于补缺，不另做一份周计划。
- 多数短示例独立运行；第23章的累计代码共享同一模块，由学习者契约整体验收。
- [20步项目验收与工具循环契约](../../tests/learner/练习说明.md)指定自己的实现；默认测试主要验证仓库参考代码。
- 真实模型、HTTP、持久化与部署按[装配手册](../project-practice/从实验到项目交付.md)继续，分别记录已验证范围。
- 学完第23章可先做AI应用作品反馈；第24–26章增加工具、批准与恢复；第27–28章按需选修。

# Python、项目工程与 AI 开发实战教材

**面向有 Java 后端经验、希望转向 Python / AI 应用开发的学习者。**

本书按“运行与数据 → 调用与状态 → 程序与交付 → 可靠服务 → 模型检索与评测 → 知识问答 → 受控动作与恢复”展开，分为五卷30章。每章在同一文件中提供基础知识、原理推导、逐步走读、独立练习、验收与面试追问。

正文先解释概念和基本用法，再通过状态变化与反例推导机制，最后连接到项目。语言卷持续使用订单数据；工程卷把订单程序变成服务；AI部分在这些边界上构建DocPilot和ProcureAgent。本册教材是Python与AI的学习主线，附录任务与里程碑用于验收对照。

每章以一个具体问题开场，在基础讲解中分步推进完整案例，代码之后解释发生了什么、为什么以及改动条件会怎样。第6部分有可展开的自测参考推导，先自己预测再查看。先从[第3章的订单筛选、分组与复制](03-容器、推导式与数据转换.md)或[第4章从函数到装饰器](04-函数、作用域、闭包与装饰器.md)可以看到这种讲法。

## 全书的连续知识主线

先按[导读的整体模型](00-导读与学习方法.md#先建立一套模型再增加新机制)理解进程、对象存储、引用与执行状态，再读函数和容器。推荐首轮入口是第1章2.1–2.5；函数调用和栈帧在第4章2.2继续。CPython实现细节设为进阶，不作为读懂赋值的前置。

| 主线 | 递进 | 形成的能力 |
| --- | --- | --- |
| 运行与数据 | 进程/堆栈概念→对象与引用→值→容器 | 解释数据怎样存在与改变 |
| 调用与生命周期 | 帧/参数/返回→作用域→暂停/异常/清理→类 | 解释状态、共享和退出 |
| 程序与交付 | 模块→外部格式→契约→验证→调度→项目 | 将语言机制组合成可维护程序 |
| 服务与AI | 可靠调用→持久状态→来源→模型/工具→评测 | 交付可追溯、受控和可恢复的应用 |

每章开头给出承接和产出；目录提供顺序，正文讲机制，附录用于自测与记录，不另开重复学习路线。

## 阅读方式与范围

1. 先在[学习导航](../学习导航.md)确定起点和本阶段作品。读一个新主题时，用[导读](00-导读与学习方法.md)找配套练习；复习时按[知识覆盖与阅读层次](附录A-知识覆盖与阅读层次.md)查漏。
2. 每章统一为八部分：目标与前置 → 基础知识 → 原理 → 示例 → 练习 → 验收 → 面试迁移 → 小结参考。
   第8部分设“主要知识点总结”和“日常工作注意事项”，按章提炼关键结论、常见错误与建议做法，方便复习与工作查阅。
3. 按[导读中的前置关系与阶段验收](00-导读与学习方法.md#知识的依赖关系与阶段验收)推进；[P01–P60任务索引](附录B-语言练习任务索引.md)与[项目里程碑](附录E-项目里程碑与交付检查.md)用于检查交付，不另行执行一套周计划。章节不等于一晚或一周，难章可分多次。
4. 项目主线仍为订单工具、DocPilot、ProcureAgent；避免为每个概念新开独立项目。
5. Python 以当前项目3.12兼容语法为基线；第三方库按当前官方入口学习，实践时锁定实际版本，不承诺任意最新SDK与旧示例完全兼容。

“完整”指从语言到应用工程、Agent和面试的学习闭环，不穷尽全部计算机/AI学科。数学推导、训练与微调、GPU推理优化等设为 [扩展方向](附录F-术语与面试手册.md)，按目标岗位进一步学习。

首轮按编号学习1–26章，完成订单工具、DocPilot与ProcureAgent三个累计成果；第27–28章是按需扩展，第29–30章用于已有作品的解释与面试。AI应用方向可在第23章交付后先做岗位反馈，不必先学Agent。进阶的训练数学、模式匹配和工具共享按各章标记回看，不能阻塞基础成果。

第18章先完成token、消息、结构与调用，再看3.5–3.6的注意力和训练推导；第22章先做问答和引用评测，工具轨迹的实际模型比较放到第26章。完整环境与运行命令仍集中在[项目装配手册](../project-practice/从实验到项目交付.md)，避免从多个周计划寻找入口。

## 示例与练习状态

- 卷一包含E01–E24原理实验和B01–B12独立基础示例，后续章节还有B18/B20/B21/B26等离线机制示例。E/B/L编号保留原材料索引，学习顺序以章节前置关系为准；部分练习已移动到相应知识之后。
- S编号是分步学习例子的稳定索引，随内容移动仍保留原编号；T10是需要pytest收集的教学测试；F编号与原有框架片段需要相应依赖。每个Python代码块按独立示例阅读，不假定共享其他代码块的变量。
- 框架片段、项目契约、真实模型调用和部署需要对应依赖、数据与服务，不能当作已完成或已全链路验证的系统。
- 旧 `practice/python_ai_course/checks_*.py` 覆盖一部分基础任务，未实现时会失败；其他练习需按验收要求自行添加检查。
- 资料核对日期：2026-11-04。参考入口和 [版本与复习方法](附录F-术语与面试手册.md)放在附录。

2026-11-05补充核对Python队列/类型、模型聊天协议与知识生命周期相关内容，补强第6–7、9、11、18、20、22、24–25章。具体发现与验收案例见[覆盖检查](附录A-知识覆盖与阅读层次.md)；新增真实服务模板仍按依赖与环境另行验证。

## 1. 学习目标与前置知识

把知识变成可推导、可验证的回答。前置：各卷核心章节。

**本章从这里开始：** 面试官把默认列表题换成嵌套配置，背过的输出不再够用。原理学习的目标，是条件变化后仍能从对象、状态和边界推导结论。

## 2. 基础知识讲解

### 2.1 用机制组织回答

技术回答先定义概念和适用边界，再说明机制，再用小例子证明，最后连接工程后果。Python题尤其要区分语言语义与CPython观察，不把某个id、缓存或字节码现象当通用规则。

### 2.2 代码题是理解的检验

面试常从一个正常例子追加空输入、错误类型、顺序或资源要求。写代码前复述约定，先做清楚的正确实现，再考虑复杂度。仅背熟一段去重代码，遇到同ID冲突、首见顺序和输入不变就可能无法调整。

#### 案例推进：从一个反例开始，而非背定义

```python
# study-example: S29A
def configure(options={"labels": []}):
    options["labels"].append("used")
    return options
one = configure()
two = configure()
assert one is two and one["labels"] == ["used", "used"]
```

先解释def执行时创建默认对象，两次调用绑定到同一字典，再解释内层列表修改共同可见。追问时可依次改变：显式传入新字典、只浅复制外层、返回结果后再修改、并发调用。每个变化继续画对象关系，不需要重背一份答案。

### 2.3 工程题沿故障传播分析

面对偶发超时或重复写入，先确认边界与证据，再检查请求预算、重试、动作状态、幂等和恢复。不要未定位就建议换框架；要说明还缺哪些日志和实验，才能继续判断。

#### 案例推进：工程题同样沿时间线推导

超时先定义等待哪个阶段，再画远端写入与本地确认的先后；异步失败先区分错误已传播、兄弟任务已退出、线程已停止；RAG先检查来源、版本、权限与语义，再谈模型质量。语言题与系统题共享同一种推导方法。

### 2.4 AI题拆成可验证层

模型结构、概率生成、数据检索、Schema、授权和执行约束分别解释。RAG答错先定位解析/召回/排序/生成，Agent失败再区分参数、工具、循环和状态。提到某工具名称后，能说出它解决的问题与代价。

### 2.5 用三轮追问发现缺口

第一轮90秒口述结论，第二轮写小实验，第三轮改变条件推演。能解释新结果比重复原答案更重要；不确定的版本细节说清查证方式，复习时回到官方说明和实际验证。

#### 案例推进：用三轮追问检验理解

第一轮给准确结论，第二轮解释机制并写最小例子，第三轮改变输入、失败位置或资源限制。记录解释卡住之处，回到相应章补实验。不了解的实现细节说明版本与验证方法，避免将CPython一次观察当作全部Python保证。

## 3. 原理讲解与推导

### 3.1 可迁移解释区别于输出记忆

同一机制能解释多个例子。默认参数、闭包和装饰器时机都能从定义/调用的时间线推导；只记某次输出无法面对换条件的追问。

### 3.2 证据决定结论能说多大

个人练习、固定集实验和真实生产经历提供不同范围证据。只说自己能复现的结论，承认未测部分，并给出下一步验证计划。

## 4. 示例与逐步走查

### 一道题的三层回答

题目：默认参数为什么会共享？先说明默认表达式在定义阶段求值；再写两次调用使用同一列表的实验；最后解释请求级默认对象如何造成状态串联，并给None/哨兵/工厂等适合场景的修复。

追问：默认值绑定的是字典或自定义对象呢？闭包里绑定可变对象是否自动复制？这时若只能背例子输出，说明机制还需要复习。

### 4.1 沿输入到结果逐步解释

默认参数题先回答定义时求值，再写两次调用共享列表；追问默认字典或闭包可变配置时，沿对象和绑定继续推导。若只能复述列表结果，就回到函数章重新验证。

## 5. 动手练习

### 练习一：三轮追问

从附录选语言、工程、AI各3题，每题先90秒说定义与边界，再解释机制、写最小例子，最后接受一次改变条件的追问。记录哪里只能背结论、哪里缺实际证据。

### 练习二：现场定位

给自己的项目保留三个可重复失败：共享可变状态、异步未正确退出、无证据却给答案。只给现象和输入，限时缩小范围、定位、修复并补回归；记录推理依据。

### 练习三：迁移验证

将默认列表改为嵌套配置、将读取超时改为写入超时、将单文档答案改为版本冲突。先预测变化再实验，用同一机制解释新的结果。

## 6. 验收与自测

**行为验收：** 核心概念、反例、应用和限制四项齐全；承认不确定点并给查证办法。

**原理验收：** 合上资料解释本章一个机制，预测一个反例，说明规则属于语言语义、库约定还是实现观察。

**提交证据：** 实现位置、运行命令、正常案例、至少一个错误/边界案例、一次失败原因和修复记录。自动检查只证明其覆盖行为；未实现任务不因示例通过而算完成。

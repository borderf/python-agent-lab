3. 用户说想要某功能时如何找替代方案？
4. 两周MVP怎样选择范围？
5. 为什么失败、空和无权限也需要原型？
6. 如何验收一条纵向切片？
7. 留存分母和队列起点怎样定义？
8. 为什么前后提升不直接证明因果？
9. 人工复核成本如何改变AI产品价值？
10. 为什么贡献毛利不等于净利润？
11. 试用后不使用该调查什么？
12. 什么证据会让你停止当前创业方向？

按“定义→真实或模拟例子→反证→下一步”回答，保留证据限制。

## 资料与核验边界

资料入口核对日期：2026-11-06。正文引用GOV.UK研究和衡量服务、W3C WAI、MDN前端与无障碍、Microsoft实验研究及SBA商业计划入口；链接在各章。教材是独立组织的教学内容，访谈、定价、规模及数字若未另标均为虚构算例。

离线脚本不访问真实用户、付款或外部服务。软件界面、模型质量、销售和客户试点需要后续实际验证。商业计划资料不构成适用当地法律、税务或融资建议；专业统计与经营问题按实际情境继续学习。

## 覆盖层次与后续专修

| 主题 | 本书掌握要求 | 深入方向 |
| --- | --- | --- |
| 研究与定位 | 过去行为、证据、分群和替代 | 定量研究、行业与竞品深研 |
| 产品与交互 | 范围、状态、可用性和无障碍 | 视觉、设计系统、复杂交互 |
| 全栈交付 | 完整任务切片与失败反馈 | 前端工程化、多端和性能 |
| 指标与实验 | 口径、队列、对照和结论边界 | 统计推断、功效与因果分析 |
| AI产品 | 评估、人工复核与支持范围 | 行业质量体系、模型专项 |
| 商业与销售 | 购买者、成本、渠道和试点 | 专业销售、定价研究与客户成功 |
| 经营与创业 | 资源、现金、责任和决策点 | 会计税务、股权融资与当地法规 |

不要用“终身价值=收入除以流失率”在少量早期客户上制造精确估计。增长、流失、毛利和支持成本随队列而变，应先积累真实数据。实际收费、营销和用户研究需要按场景落实授权和责任。

## 校验方式与范围

在仓库根目录运行：

```powershell
.venv\Scripts\python.exe -X utf8 scripts\verify_learning_tracks.py
.venv\Scripts\python.exe -X utf8 scripts\verify_learning_tracks.py --static-only
```

第一条检查新教材01–14编号、八部分、自测、代码语法、全仓库本地链接与锚点，并运行本地幂等、指标成本和搜索HTTP契约三个实验。第二条只做静态检查。原Python教材的30章结构与例子统计仍由原检查器负责，本命令只复用其静态检查，不重复执行原有离线例子。

浏览器视觉、键盘交互、真实模型、外部数据库、云部署、压测及客户商业效果另行验证。最终结果与剩余范围见[教材整理记录](../教材整理记录.md)。改变依赖和环境后重新核对。

# 产品、创业工作簿与验收模板

[本书目录](教材目录.md)

每份成果写日期、场景、版本、证据来源与限制。可复制到practice/product_labs的自建记录；真实敏感数据不提交仓库。

## P1　机会与假设

```text
谁在什么情境下完成什么任务：
障碍、频率、后果、当前替代：
使用者 / 购买者 / 数据负责人：
价值假设 / 可行性 / 采用 / 付费：
事实、假设、未知分别列出：
最危险假设 / 低成本验证 / 反证：
```

示例：采购专员反复核对补件；是否真实、是否高频、是否能获得资料都待验证。不要直接把“需要Agent”写成问题。

## P2　研究与证据

```text
研究目标 / 招募条件 / 差异样本：
许可、匿名、记录和保留方式：
过去行为问题：最近一次 / 步骤 / 耗时 / 替代 / 后果
证据ID / 原话 / 观察 / 解释 / 待核实：
支持与反例 / 样本偏差 / 下一步：
```

示例：R01原话“主要在等证件”，H01推断“跟踪补件比写报告重要”。下一步观察授权流程，H01尚非事实。

## P3　定位与产品规格

```text
目标客户适配条件与排除条件：
当前替代及其优势：
价值主张 / 购买人 / 采用障碍：
结果目标 / 最小范围 / 不做范围：
任务流程 / 界面状态 / 权限 / 异常 / 人工接管：
验收输入、步骤、预期、护栏：
版本与变更理由：
```

## P4　交互与纵向切片

| 状态 | 用户看到什么 | 可做动作 | 服务端约束 |
| --- | --- | --- | --- |
| 加载 | 处理中及必要进度 | 取消等待/稍后查 | 任务是否仍运行须说明 |
| 无证据 | 缺少依据 | 改查询/补资料 | 不假装通过 |
| 无权限 | 有限错误反馈 | 联系负责人 | 不泄露他人资料 |
| 待确认 | 动作与载荷版本 | 改/拒绝/确认 | 执行点再授权 |

记录一条完整切片：界面→接口→规则→存储→返回→观察。试一次断网、刷新和重复点击，说明副作用与恢复。

## P5　指标与事件

```text
目标 / 主要指标 / 护栏：
主体单位（用户/账户/企业/任务）：
分子 / 分母 / 窗口 / 队列起点 / 事件时间：
事件名称 / 触发 / 字段 / 去重 / 版本 / 数据源：
过滤测试账户与异常数据的方法：
计算输入、公式、结果与局限：
```

教学口径：邀请20，激活8，次周激活队列回访5；激活率8/20，队列留存5/8。定义不同会得到不同数值，先写定义再算。

## P6　实验与AI评估

```text
假设 / 对照 / 方法选择理由：
样本来源 / 分组单位 / 周期 / 数据质量：
主指标 / 护栏 / 预设停止与决定规则：
AI题集版本 / 评分规则 / 评审分歧：
结果、反例、不确定性、未覆盖人群：
继续 / 修改 / 停止及证据：
```

小样本试点不能随意声称统计显著。模型质量、用户任务和业务收益分层评价。

## P7　定价、获客与现金情景

```text
收费对象、单位、周期、含量、超额与退款假设：
每客户收入 / 模型 / 存储 / 支持 / 其他可变成本：
贡献毛利 = 收入 - 按当前口径的可变成本
获客投入、渠道、销售周期、采用和续用：
固定成本、收付款时间、现金余额：
乐观 / 基准 / 悲观情景及缺失数据：
```

纯虚构：2000-400-200-500=900，贡献率45%；不是净利润。若获客3600且贡献稳定、客户持续付费，贡献回本约4个月；流失、折扣与账期会改变判断。

## P8　试点与经营决策

```text
客户、使用者、购买者及数据负责人：
范围 / 期限 / 双方责任 / 接入与退出：
成功标准与护栏 / 证据采集 / 限制：
支持、故障、数据保留与删除安排：
个人时间、现金和其他约束：
下一阶段投入 / 继续、调整或停止标准：
复盘：原假设 / 新证据 / 改变的决定 / 下一步
```

## P9　阶段评分与答辩

| 阶段 | 必交成果 | 新条件 |
| --- | --- | --- |
| 1–3 | 研究、机会、定位 | 新群体或反例 |
| 4–6 | 规格、原型、切片 | 断网、无权限、范围减半 |
| 7–9 | 指标、实验、AI评估 | 重复事件或错误答案 |
| 10–14 | 定价、试点、运营、决定 | 拒绝付费或成本翻倍 |

每项0–3级：未学、解释、独立应用、证据驱动迁移。答辩：谁的问题？证据？取舍？效果？代价？下一步？缺少真实用户时明确模拟，不能计为真实商业验证。

## P10　离线计算实验

[漏斗、留存与成本算例](../../practice/product_labs/metrics_and_cost.py)用虚构事件验证去重、跨窗口与分母，以及贡献毛利和成本压力情景。

```powershell
.venv\Scripts\python.exe -X utf8 practice\product_labs\metrics_and_cost.py
```

结果只验证计算，不能证明获客、市场需求或因果提升。挑战：改变队列起点和价值事件，重新定义口径并预测数字。

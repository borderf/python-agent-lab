## 1. 目标、前置与问题

前置：第2、7章。能按不确定性选择验证方式并解释结论边界。问题：上线后转化提高，就能归因于新功能吗？

## 2. 概念与基础

先给新人一个原型任务，观察能否找到按钮，检验的是理解与操作；再让真实团队按约定资料试用，检验任务价值与交付。固定题集的离线评测检查系统在那些题上的表现。只有在具备适当分配与测量条件时，才考虑随机A/B估计变化的影响。先确定问题，再选择实验方法与样本计划。

实验先写假设、目标群体、分配单位、主要指标、护栏、样本与周期计划，以及停止和决策规则。统计显著不等于业务收益足够；未显著也不证明完全无效。样本需求依基线、目标差异、显著水平和功效等决定。

## 3. 机制与推导

实验先写要改变什么、为什么会影响任务、怎样被结果推翻。只比较新旧版本的总访问量，可能同时受到渠道、用户结构、季节和埋点变化影响，无法把变化都归给功能。

随机分配有助于减轻混杂，但要考虑用户之间是否相互影响。一个团队共同使用资料时，按个人分组可能互相污染；按团队分组又需要足够团队，不能把每条点击当独立样本。

小流量时优先排除明显问题：固定题集检查正确性，原型观察理解，限定试点检查采用。它们各自减少未知，不必勉强给三个人的结果套显著性结论。前后观察要说明不受控变化。

提前定义主指标、护栏、分配单位、窗口与停止条件。不能看到一个指标上涨就停止，也不能看到错误增多就换一个好看的指标。产品决定需要同时考虑收益、不确定性与错误后果。

## 4. 案例逐步推演

假设要验证“摘要是否帮助用户完成查证”。先用相同题集核对事实与引用，再观察用户是否把摘要当成无需复核的结论。

虚构数据 A 完成40/100，B完成45/100。差值是5个百分点，相对变化是12.5%；这只是观察差，不能直接称为稳定提升。继续检查分组、独立性、埋点与样本不确定性。

若 B 的关键错误从0变为3，即使完成率更高，也应暂停扩大，逐题核对错误后果。下一步可能是保留摘要但强化来源、缩小任务范围，或暂时移除生成。把决定与预设护栏连起来，而不是事后解释所有结果都算成功。

### 4.1 把观察差与结论分开计算

```python
# track-example: P08
from fractions import Fraction
a = Fraction(40, 100)
b = Fraction(45, 100)
absolute_change = b - a
relative_change = absolute_change / a
assert absolute_change == Fraction(5, 100)
assert relative_change == Fraction(125, 1000)
```

代码只证明算术：5个百分点和12.5%相对变化。它没有检查随机分配、样本独立、区间或错误护栏，因而不能得出“B稳定提升”。把计算正确和实验解释正确分开验收。

一份计划可以写：“摘要可能降低查证理解成本；主指标是独立找到正确原文；护栏是关键错误和总完成时间；先做固定题与任务观察，再根据流量决定是否进入随机实验。”若用户只是因为第二次更熟练，记录学习效应并调整比较顺序。

预先决定遇到关键错误如何停止扩大。计划允许坏消息改变范围，才是真正的验证，而不是为已开发功能寻找一个上涨数字。

#### 要检出 5 个百分点，需要多少样本

比例指标的两组比较可按 `n ≈ 2 × (z(1-α/2) + z(power))² × p(1-p) / δ²` 估算每组样本量。取 α=0.05、power=0.8、基线 40%、目标差异 5 个百分点：

```python
# track-example: P11
from statistics import NormalDist
from math import sqrt

z_alpha = NormalDist().inv_cdf(0.975)
z_beta = NormalDist().inv_cdf(0.8)
p, delta = 0.40, 0.05
per_group = 2 * (z_alpha + z_beta) ** 2 * p * (1 - p) / delta ** 2
half_width = 1.96 * sqrt(2 * p * (1 - p) / 100)
assert round(per_group) == 1507
assert round(half_width * 100, 1) == 13.6
```

每组约需 1,507 个独立样本；只有 100 人/组时，95% 区间半宽约 13.6 个百分点，看到“40/100 对 45/100”不能说明 5 个百分点真实存在。样本单位还要与分配单位一致：按团队分配时，团队数才是样本量，不能把每个人的点击当作独立观测。

## 5. 分层练习

先完成：写一页实验计划：一个假设、一个主指标、两条护栏、分配或比较方法、观察窗口与继续条件。样本不足时，改用任务观察并说明可得结论，不强行宣称因果。

完成后换一个约束或一组输入，解释原决定哪里需要改变。基础任务通过后再做深化；本章不要求把所有扩展同时实现。

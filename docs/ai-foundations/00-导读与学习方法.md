# 导读：把 AI 原理学成可解释的链条

[全书目录](教材目录.md) · [Python 与 AI 教材](../python-book/教材目录.md)

## 为什么应用开发者也要懂原理

会调 API 不等于能解释系统为什么失败。面试官追问“为什么温度调低仍有幻觉”“Recall@5 高为什么答案还是错”“LoRA 为什么省参数但不一定省显存”，考的不是术语，而是你能否把**数据流、训练目标、推理过程和评测口径**连起来。

本册的目标不是把你训练成算法研究员，而是让你：

1. 看见一个 AI 现象，能判断它发生在 tokenizer、表示、注意力、训练、推理、检索还是评测层；
2. 能用一个最小数字例子解释机制，而不是只背结论；
3. 能说清一个方法的适用边界和失败模式；
4. 能在面试中用“定义→机制→例子→边界→验证”组织回答。

## 先建立一张总图

```text
文本 --tokenizer--> token 序列 --embedding--> 向量
     --Transformer(注意力/前馈/残差/位置)--> 上下文表示
     --输出层--> 下一个 token 的概率分布
     --采样/解码--> 新 token --> 拼回上下文，继续
```

训练改变的是参数；推理使用的是固定参数和当次上下文。RAG 改变上下文，微调改变参数，提示改变指令与示例；三者不是同一层。

## 三个必须分清的概念

| 概念 | 是什么 | 不是什么 |
| --- | --- | --- |
| token | 模型处理的离散单位 | 不等于汉字、单词或字符 |
| embedding | 把对象映射成向量 | 不等于“模型理解了事实” |
| 概率 | 下一 token 的分布 | 不等于事实置信度或业务正确率 |

## 数学最小工具箱

- **点积**：两个等长向量对应位置相乘再相加，衡量方向/相似度的一部分。
- **softmax**：把一组实数变成非负、和为 1 的权重；减最大值只为数值稳定，不改变比例。
- **交叉熵/负对数损失**：正确 token 概率越低，惩罚越大。
- **余弦相似度**：点积除以两个模长，范围在 -1 到 1（零向量要单独处理）。

每章只引入当前需要的数学；不要求先学完线性代数。

## 怎样算“学会”

合上资料，能完成下面任意两项：

- 用 3 个 token、2 维向量手算一次注意力权重；
- 解释 BPE 为什么会把常见词合并成一个 token；
- 解释 temperature、top-p、top-k 分别改什么；
- 解释 RAG 失败时如何区分“没召回”和“召回了但没用好”；
- 给一个指标说明它的分母、偏差和适用条件。

## 与 Python 教材的读法

- 先读本册 01–04，建立 token/向量/注意力直觉；
- 读 Python 第18章，落地消息、结构化输出、流式与适配；
- 做 RAG 前读本册 07，做评测前读 08；
- 读完后用 09 的同一案例复述全链，再回 Python 第18–22章落地。
- 面试前用附录A自测，按“先答→核对→换条件”复述。

# 第01章　一张地图：从文本到行为

[上一章](00-导读与学习方法.md) · [全书目录](教材目录.md) · [下一章](02-Tokenizer.md)

## 1. 学习目标与前置知识

能把一次大模型调用拆成 tokenizer、表示、Transformer、输出分布、采样和系统边界几层，并说清训练与推理各改变什么。前置：会基本编程；不要求微积分。

**本章从这里开始：** 用户输入“预付款上限是多少”，模型输出一段流畅回答。中间发生了什么？如果回答错了，是 tokenizer、模型参数、上下文、采样还是检索的问题？这一章先给一张可定位故障的地图。

## 2. 基础知识讲解

### 2.1 模型不是“查数据库”，而是逐步预测

自回归语言模型的核心动作只有一句：**给定已有 token，预测下一个 token 的概率分布；选一个，追加到上下文，再预测下一个。**

```text
输入：查询 预付款 上限 是 多少
预测：下一 token 概率分布
选择：？ -> “预”
追加：查询 预付款 上限 是 多少 预
再预测：下一个 token -> “付”
...
```

“回答”是很多次小预测拼起来的序列，不是一次性从知识库取出完整句子。这解释了三个现象：

- 输出可以很流畅，但事实可能错；
- 同一问题多次调用可能不同（采样）；
- 上下文里给什么证据，会直接影响下一步概率。

### 2.2 五层地图

| 层 | 回答的问题 | 典型失败 |
| --- | --- | --- |
| Tokenizer | 文本被切成什么单位？ | 中文/代码 token 数估算错、特殊字符异常 |
| 表示/Embedding | 每个 token 变成什么向量？ | 把 token 向量当成句子语义向量 |
| Transformer | 上下文怎样互相影响？ | 长文定位差、注意力被无关内容分散 |
| 输出/采样 | 下一个 token 怎样选？ | 温度/截断设置导致重复或跑偏 |
| 系统边界 | 证据、权限、工具、评测 | RAG 没召回、越权、指标选错 |

训练发生在“参数”这一层；推理发生在“本次上下文 + 固定参数”这一层；RAG 发生在“上下文”这一层；微调又回到“参数”层。排查时先定位层，再谈方法。

### 2.3 一个最小概率例子

假设下一个 token 的 logits 为：

```text
“预” 2.0
“付” 1.0
“退” 0.0
```

softmax 后约为 `0.665 / 0.245 / 0.090`。

- 贪心解码选概率最高的“预”；
- 按分布采样可能选“付”；
- temperature 改变分布的平坦/尖锐程度；
- top-p/top-k 先裁掉一部分候选再采样。

概率高只表示“在这个上下文下更可能”，不表示“事实为真”。模型可能对错误内容给出高概率，因为训练数据里这种说法常见。

### 2.4 训练与推理不是一回事

| 阶段 | 做什么 | 改变什么 |
| --- | --- | --- |
| 预训练 | 大量文本上预测下一 token | 参数 |
| SFT | 用示例教“怎样回答任务” | 参数（或部分参数） |
| RLHF/DPO | 用偏好让输出更符合人类选择 | 参数/策略 |
| 推理 | 用固定参数处理当前输入 | 不改变参数 |
| RAG | 把检索证据放进上下文 | 不改变参数 |
| 提示 | 改变指令/示例/格式 | 不改变参数 |

面试里常见的错误是把“模型不知道新政策”直接归因于“需要微调”。如果知识每天变化，RAG 通常更合适；如果是固定格式/风格/任务行为，SFT 或提示可能更合适；如果是基础能力不足，才考虑更大模型或训练。

### 2.5 系统边界为什么必须存在

模型优化的是“下一个 token 的预测”，不是“事实正确”“有权访问”“操作可回滚”。所以系统要补：

- 检索与引用：给事实来源；
- 权限与租户：在检索/执行前过滤；
- 工具审批与幂等：写操作不能只靠模型判断；
- 评测：用独立数据证明有效，而不是看一次演示。

## 3. 原理讲解与推导

### 3.1 为什么“预测下一个 token”能表现成理解

要准确预测下一个 token，模型必须从上下文里提取语法、语义、实体关系和任务模式。注意力让不同位置互相读取，前馈层做特征变换，多层堆叠形成抽象表示。但“能预测”不等于“有事实数据库”或“有稳定推理保证”；它学到的是训练分布中的统计规律。

### 3.2 上下文是“工作记忆”，不是永久记忆

本次输入、历史消息、检索证据、工具结果都占上下文窗口。窗口是 token 上限，不是字符上限；超出后要截断、摘要或检索。窗口变大不等于模型能同等可靠地使用每个位置，长上下文仍有定位和“中间遗忘”问题。

### 3.3 参数记忆与非参数记忆

- **参数记忆**：训练时压进权重的知识，更新慢、难溯源、可能过时。
- **非参数记忆**：检索库、数据库、文件，更新快、可引用、可权限控制。

RAG 把非参数记忆放进上下文；微调把行为/知识写进参数。两者可以组合，但要先问“更新频率、可追溯性、权限、成本”四个约束。

## 4. 示例与逐步走查

```python
# runnable
import math

logits = {"预": 2.0, "付": 1.0, "退": 0.0}

def distribution(logits, temperature=1.0):
    scaled = {token: value / temperature for token, value in logits.items()}
    total = sum(math.exp(value) for value in scaled.values())
    return {token: math.exp(value) / total for token, value in scaled.items()}

print(distribution(logits, 0.5))
print(distribution(logits, 2.0))
```

模型输出的是 logits，不是概率；softmax 才把 logits 变成概率。温度不改变客观事实，也不保证提升事实性；但它改变生成分布，因此**可能改变本次生成的答案是否正确**。温度小于 1 更集中，大于 1 更分散。

逐步检查：

1. 输入被 tokenizer 切成 token；
2. 每个 token 变成向量，进入 Transformer；
3. 最后一层输出词表上的 logits；
4. softmax + 温度/截断得到采样分布；
5. 选中的 token 追加回上下文，继续下一轮。

## 5. 练习

### 练习一：跟写

用三个候选 token 和不同 temperature（0.2、1、2）手算 softmax 分布，说明哪个更集中、哪个更平坦。

### 练习二：改造

给上面的 `distribution` 增加 top-k：只保留概率最高的 k 个候选，重新归一化。说明 k=1 与贪心解码的关系。

### 练习三：独立

选一个你熟悉的 AI 应用失败案例，画五层地图，标出“首个失真层”和“为什么不是其他层”。例如：回答引用了旧制度，是检索层、上下文层还是模型层？

## 6. 验收与自测

**行为验收：** 能画出自回归循环；能解释 token/概率/采样/上下文/参数各在哪一层；能说出一个“模型没错但系统错”的例子。

**原理验收：** 能说明“预测下一 token”为什么能表现成理解，以及它的边界；能区分参数记忆与非参数记忆。

temperature=0 是否保证同一问题每次输出完全一致？

## 7. 面试问答与参考回答

**问：大模型生成回答的本质是什么？**

自回归地预测下一个 token：根据已有上下文输出词表上的概率分布，选一个 token 追加，再继续。回答是多次预测拼成的序列，不是从知识库一次取出。

**问：为什么模型会“胡说”？**

训练目标是预测概率，不是保证事实；参数记忆可能过时/缺失，上下文可能没有证据，采样会选到低概率内容。系统要用检索、引用、校验和评测补事实边界。

**问：RAG、微调、提示各改哪一层？**

RAG 改上下文（外部证据），提示改指令/示例，微调改参数/行为；知识频繁更新优先 RAG，固定格式/行为可考虑微调，基础能力不足才考虑更大模型/训练。

## 8. 本章小结与参考

### 8.1 一页知识地图

**本章主问题：** 从用户输入到一段流畅回答，中间经过哪几层，答错时该去哪一层找原因？

**一条主线：**

```text
输入文本 → 切 token → 向量/注意力 → logits → 温度+截断采样 → 拼成回答
```

**三个关键词：** 自回归、五层地图、参数与上下文——自回归决定回答是逐 token 拼出来的，五层地图决定先定位哪一层，参数/上下文的区分决定该训练还是该检索。

**最容易错：**

- 把回答当成一次性从知识库取出，忘了它是逐 token 采样拼成的序列；
- 用温度调事实：概率高只说明在这个上下文下更可能，不说明为真；
- 把“模型不知道新政策”直接归因于微调，而知识高频更新应先考虑 RAG；
- 只盯着模型，不补检索、权限、审批和评测这些系统边界。

**与前后章：** 上一章（导读）只给学习方法和章节链，不碰模型内部；下一章要拆开地图第一层——文本究竟怎样被切成 token。

**学完应能：**

- 画出一次调用的自回归循环，标出 token、logits、softmax 与采样位置；
- 用五层地图给一个真实失败案例定位首个失真层，并说明为什么不是其他层；
- 区分参数记忆与非参数记忆，判断一个需求该改参数、改上下文还是改提示；
- 解释 temperature 为什么改变本次答案却不修复事实。

# AI 基础原理：从 token 到可评测系统

[导读](00-导读与学习方法.md) · [Python 与 AI 教材](../python-book/教材目录.md) · [学习导航](../学习导航.md)

这是一册**原理配套书**，不重复 Python 教材里的 API、RAG 工程和 Agent 编排。它回答的是面试和排障时最容易被追问的那一层：

- 模型看到的“文本”到底是什么？
- 为什么下一 token 预测会表现成“理解”？
- 注意力、Transformer、训练和推理各在做什么？
- 幻觉从哪里来，RAG/微调/提示各能修什么？
- 怎样用指标和实验证明一个模型或系统真的更好？

## 和 Python 教材的关系

- Python 第18章负责“怎么调用模型、消息、结构化输出、流式与适配”；本册解释它背后的机制。
- Python 第20–22章负责“怎么建 RAG、检索、权限和评测”；本册解释 embedding、向量空间、指标和偏差。
- Python 附录I提供注意力/向量/损失的手算实验；本册把同一组概念连成体系。
- 先读本册第1–4章，再读第18章，应用细节会更容易落地；第5–8章可在做 RAG/评测时回读。

## 怎样读

每章按“直觉 → 机制 → 小数字例子 → 工程含义 → 面试追问”展开。不要背公式名称；要能用手算一个 2×2/3×3 例子，说明每一步在做什么、边界在哪。

书中数学只用到点积、指数、归一化和对数。遇到矩阵，先写形状，再写每一格的含义；遇到概率，先问“分母是什么”。

## 面试用法

先自己回答每章末尾的“面试追问”，再看 [附录A](附录A-面试题与参考回答.md) 的参考答法。答案统一按：

```text
一句话定义 → 关键机制 → 一个小例子 → 工程边界/失败模式 → 如何验证
```

只背结论很容易在第二轮追问露馅；能画出数据流、说出一个反例，才算掌握。

## 不覆盖什么

反向传播的完整推导、CUDA 内核、分布式训练实现、具体供应商的私有训练细节不在本册范围。应用岗位先掌握机制、边界、指标和实验；训练/平台岗位再补线性代数、概率、优化器与工程实现。

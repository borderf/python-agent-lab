## 1. 学习目标与前置知识

能用自己的话解释 Q/K/V、缩放点积注意力、softmax、多头、因果掩码、位置信息、残差/归一化和前馈层，并说清注意力的计算代价与常见误解。前置：第3章；会点积和指数即可。

**本章从这里开始：** “苹果”在“苹果手机”和“吃苹果”里含义不同。模型怎样让当前位置读取上下文，而不是孤立地看每个 token？

## 2. 基础知识讲解

### 2.1 一句话版本

Transformer 的一层大致做两件事：

1. **注意力**：每个位置根据 Query 与所有可见位置的 Key 匹配，加权组合 Value；
2. **前馈网络**：对每个位置独立做非线性变换。

再配合残差、归一化、位置信息和多层堆叠，得到上下文表示。

### 2.2 Q/K/V 是什么

把输入表示 `X`（n 个 token，每个 d 维）分别乘三个学习矩阵：

```text
Q = X W_Q
K = X W_K
V = X W_V
```

- Query：当前位置“想找什么”；
- Key：每个位置“能被怎样匹配”；
- Value：每个位置“提供什么内容”。

Q/K/V 都是训练得到的投影，不是人类规则；“注意力权重大”也不等于“这个 token 对结论最重要”。

### 2.3 缩放点积注意力

```text
scores = Q K^T / sqrt(d_k)
masked = mask(scores)          # 因果模型遮住未来位置
weights = softmax(masked, 行)
output = weights V
```

`sqrt(d_k)` 防止维度变大时点积过大、softmax 过尖。softmax 按行归一化，每一行权重非负、和为 1。

小例子（2 维，3 个 token）：

```text
Q = [[1,0],[0,1],[1,1]]
K = 同上
V = [[10,0],[0,10],[10,10]]
```

`QK^T` 的第一行是 `[1,0,1]`：查询 1 与三个键的匹配分数。因果掩码后，位置 1 只能看自己，权重为 `[1,0,0]`；位置 2 能看 1、2，权重约为 `[0.33,0.67,0]`。完整计算见 Python 教材附录I。

### 2.4 多头注意力

把 d 维拆成 h 个头，每个头有自己的 Q/K/V 投影，分别做注意力，再拼接、乘输出投影：

```text
head_i = Attention(Q_i, K_i, V_i)
MultiHead = Concat(head_1,...,head_h) W_O
```

不同头可以关注不同模式（局部、指代、语法、位置等），但“每个头有可解释的单一功能”通常是过度简化。

### 2.5 因果掩码

自回归语言模型不能看到未来 token，否则训练时就是“抄答案”。掩码把未来位置的分数设为负无穷，softmax 后权重为 0。训练和推理都必须保持这个方向。

### 2.6 位置信息

注意力本身对顺序不敏感（打乱 token 只改变对应行），所以需要位置信息：

- 正弦/余弦绝对位置编码；
- 可学习位置 embedding；
- RoPE（旋转位置编码）等相对位置方法，常见于现代开源模型。

位置编码让模型区分“A 在 B 前”与“B 在 A 前”；长上下文外推仍是研究/工程问题。

### 2.7 残差、归一化与前馈层

```text
x = x + Attention(Norm(x))     # pre-norm 常见写法
x = x + FFN(Norm(x))
FFN(x) = activation(x W1 + b1) W2 + b2
```

- 残差让梯度更容易穿过深层；
- LayerNorm 稳定每层分布；
- FFN 对每个位置独立变换，常比注意力有更多参数；
- 多层堆叠逐步形成更抽象的表示。

### 2.8 输出层

最后一层 hidden state 乘词表投影，得到每个 token 的 logits，再 softmax 成下一个 token 的概率。很多模型共享输入 embedding 与输出投影（权重 tying），但不是所有模型都如此。

## 3. 原理讲解与推导

### 3.1 复杂度

序列长度 n、维度 d，先分开看“矩阵形状、计算量、存储量”：

- Q、K、V 各是 n×d；
- 单头分数矩阵 `QK^T` 的形状是 n×n，元素数是 n²；
- 计算这个分数矩阵约需 O(n²d) 次乘加；
- 如果显式保存每个头的分数矩阵，存储约 O(h·n²) 个数值（h 为头数）；实际实现可能不物化完整矩阵，或用分块/FlashAttention 降低峰值显存；
- 前馈层约 O(n·d²)；
- KV cache 每层保存历史 K/V，约 O(n·d) 个数值（乘层数、批大小和并发）。

因此不能把“分数矩阵 n² 个元素”和“计算量 O(n²d)”记成同一个公式。上下文翻倍时，n² 的元素数和计算量都约四倍，这是长上下文昂贵的主因之一；具体显存还受头数、层数、是否保存、是否分块和实现影响。

**缩放、掩码、softmax 不是一件事**：缩放调整分数数值尺度，掩码决定哪些位置可见（例如因果模型不能看未来），softmax 把可见分数归一化成权重。漏掉缩放会训练不稳，漏掉因果掩码会让训练“看到答案”，二者不能用同一个开关代替。

KV cache 复用历史 K/V，降低逐步生成时的重复计算，但缓存本身占显存，随上下文/并发增长。

### 3.2 注意力不是“解释”

权重表示“在这个头、这一层，查询怎样分配”，不等于因果重要性，也不等于人类可读的理由。用注意力做解释要非常谨慎，最好结合扰动/归因/评测。

### 3.3 为什么需要多层

一层注意力只能做一次组合；多层可以逐步构建指代、句法、语义和任务相关表示。深层网络的残差/归一化/初始化对训练稳定性很关键。

## 4. 示例与逐步走查

```python
# runnable
import math

def softmax(values):
    maximum = max(values)
    exps = [math.exp(value - maximum) for value in values]
    total = sum(exps)
    return [value / total for value in exps]

def attention(query, keys, values):
    scores = [sum(q * k for q, k in zip(query, key)) / math.sqrt(len(query)) for key in keys]
    weights = softmax(scores)
    output = [sum(weight * value[dim] for weight, value in zip(weights, values))
              for dim in range(len(values[0]))]
    return weights, output

q = [1.0, 0.0]
ks = [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
vs = [[10.0, 0.0], [0.0, 10.0], [10.0, 10.0]]
print(attention(q, ks, vs))
```

逐步解释：

1. 点积算匹配分数；
2. 除以 `sqrt(2)` 缩放；
3. softmax 得到权重；
4. 权重乘 V 得到新表示；
5. 这是单头、无掩码的局部演示，不是完整 Transformer。

## 7. 面试问答与参考回答

**问：Self-Attention 的计算过程？**

输入投影得到 Q/K/V；Q 与 K 点积、缩放、掩码、softmax 得权重；权重乘 V 得输出；多头拼接后再投影。它让每个位置按匹配关系组合上下文。

**问：为什么要除以 sqrt(d_k)？**

维度增大时点积方差变大，softmax 容易饱和/梯度变小；缩放把分数控制在更稳定范围。它是训练稳定性的工程选择。

**问：Attention 权重能当解释吗？**

不能直接当因果解释。权重是特定头/层的分配，受多层、残差、多头和后续层影响；解释要结合扰动、归因和任务评测。

**问：长上下文为什么贵？**

注意力分数矩阵随 n² 增长，KV cache 随上下文/并发占显存；计算和内存都不是线性。分块、稀疏注意力、缓存和检索是不同层的优化。

## 8. 本章小结与参考

### 8.1 一页知识地图

**本章主问题：** “苹果”在“苹果手机”和“吃苹果”里意思不同，模型怎样让当前位置读到上下文？

**一条主线：**

```text
token 向量 → Q/K/V 投影 → 缩放点积+掩码+softmax → 加权 V → 残差/FFN 堆叠 → 上下文表示
```

**三个关键词：** Q/K/V、缩放点积注意力、位置——Q/K/V 给出三种角色，缩放点积注意力按匹配分配权重，位置信息补上注意力本身缺的顺序。

**最容易错：**

- 漏掉 `sqrt(d_k)` 缩放或因果掩码，让训练时“看到未来”；
- 把注意力权重当成因果解释或“最重要的 token”；
- 把分数矩阵 n² 个元素和 O(n²d) 计算量记成同一个公式；
- 以为没有位置编码也能分清“A 在 B 前”和“B 在 A 前”。

**学完应能：**

- 写出 Q/K/V 的形状，手算 2–3 个 token 的注意力权重；
- 说明缩放、掩码、softmax 各自解决什么问题；
- 解释多头、位置编码与残差/归一化在深层堆叠中的作用；
- 估算上下文翻倍时注意力计算量与 KV cache 的增长方向。

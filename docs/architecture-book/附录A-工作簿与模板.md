# 架构工作簿、练习与评审模板

[本书目录](教材目录.md)

复制所需模板填写，不要求一次填完。每份成果标明日期、版本、事实/假设/设计/实测与待验证项。练习可放practice/architecture_labs；模板中的目标不能直接作为生产承诺。

## A1　目标、约束与质量场景

```text
用户与任务：
成功与失败的业务后果：
明确不做的范围：
约束（时间/团队/数据/既有系统）：
事实来源及日期：
假设与最危险未知：
场景：触发 / 环境 / 期望响应 / 测量方式 / 目标依据
验证：数据 / 环境 / 命令 / 正常与失败输入 / 原始记录
```

示例：模型超时时，授权用户仍能看到当前有权访问的来源；测量从入口到完整降级响应的时长，同时检查无越权与无伪造答案。目标值留给基线和用户任务决定。

## A2　ADR与选型

```text
编号 / 标题 / 状态 / 日期 / 负责人：
背景、约束和重要质量属性：
选项A及收益、代价：
选项B及收益、代价：
决定与理由：
最危险假设与验证实验：
结果、限制和未决项：
回退路径和复查触发条件：
被替代记录与后续记录：
```

参考方向：两人团队的检索原型先模块化单体；理由是协调和部署成本，代价是资源共享；在导入影响查询的混合负载证据出现后复查。反例：法规或组织隔离约束可能使初始独立部署成为必要。

## A3　边界与契约

| 组件 | 拥有的数据和不变量 | 公开操作 | 依赖 | 负责人 |
| --- | --- | --- | --- | --- |
| review | 审查版本与任务状态 | 创建/查询 | 文档与规则 | 待填 |
| approval | 批准绑定载荷 | 批准/拒绝/失效 | 可信身份 | 待填 |

```text
接口：主体 / 权限 / 输入约束 / 输出 / 状态 / 错误
副作用：发生在哪个提交点，是否可逆
重复：键范围 / 载荷摘要 / 保留 / 冲突 / 查询
时限：总预算 / 分段预算 / 重试 / 取消边界
兼容：旧客户端行为 / 弃用 / 契约样本
```

## A4　故障矩阵与恢复

| 故障点 | 可能已产生的效果 | 恢复动作 | 要验证什么 |
| --- | --- | --- | --- |
| 本地提交后、发送前 | outbox已保存 | 发送器继续 | 事件不会永久漏发 |
| 远端执行后、响应前 | 远端可能已完成 | 稳定键查询/重试 | 去重或人工对账 |
| 消费提交后、确认前 | 本地效果已完成 | 去重后确认 | 不重复副作用 |
| 版本更新中断 | 新旧视图共存 | 校验并继续/回退 | 来源与权限一致 |

为每行补充实际状态、输入、命令、日志、结果和限制。不能用“会重试”代替说明谁重试、次数、预算和幂等条件。

## A5　容量与成本实验

```text
数据：规模 / 大小分布 / 热点 / 读写比例 / 缓存状态
环境：硬件 / 版本 / 进程 / 连接池 / 外部限额
负载：到达方式 / 请求速率 / 并发 / 突发 / 持续时间
输出：P50/P95/P99 / 错误 / 超时 / 队列 / 资源 / 成本
对照：仅改变的变量 / 重复次数 / 原始记录
结论：采用或舍弃 / 瓶颈证据 / 未覆盖范围
```

教学计算：20次/秒×平均1.5秒≈30个平均在途请求；不是并发上限。10万次有效请求与99.5%成功目标，对应500次失败预算；必须同时满足另设的安全与正确性护栏。

## A6　发布与评审包

```text
当前与目标图：同层级、范围、协议、信任边界
数据迁移：扩展 / 回填 / 校验 / 切换 / 收缩
发布：新旧共存 / 指标 / 停止 / 回退 / 不可逆操作
运行：健康 / 告警 / 责任 / 备份 / 恢复 / 对账
评审：争议 / 实验 / 决定 / 负责人 / 复查时间
```

## A7　阶段评分与复习

| 阶段 | 必交成果 | 迁移题 |
| --- | --- | --- |
| 1–4 | 场景、ADR、边界、契约 | 新增购买者或旧客户端 |
| 5–7 | 数据约束、时间线、故障矩阵 | 重复、乱序、未知结果 |
| 8–10 | 负载、恢复、权限验证 | 流量突发或立即撤权 |
| 11–14 | 发布、选型、评审、答辩 | 供应商故障或团队变化 |

每项按0–3级记录并链接证据；关键权限、数据或副作用失败单独列阻塞项。隔一周以新条件重做一次，解释哪项旧决定应更新。

## A8　离线实验

[本地幂等与事务实验](../../practice/architecture_labs/idempotency_sqlite.py)只用标准库，在临时目录验证同键重放、不同载荷冲突、重开连接与事务回滚。运行：

```powershell
.venv\Scripts\python.exe -X utf8 practice\architecture_labs\idempotency_sqlite.py
```

第二部分模拟远端已写入、客户端缺回执。把两库重开前后的记录填入故障矩阵，再设计远端无幂等时的人工对账。真实网络、PostgreSQL 隔离和负载数据在对应环境另测。

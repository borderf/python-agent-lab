# 导读：从后端开发到架构能力

[本书目录](教材目录.md) · [Python与AI教材](../python-book/教材目录.md)

## 这套教材怎样使用

面向已有Java或其他后端开发经验的学习者。主线是约束与决策→运行与模块→接口与数据→分布式与性能→可靠性安全→演进与协作。每章包含讲解、因果推导、同项目案例、分层练习、自测推导和交付标准，可独立于产品教材学习。

DocPilot用于文档检索与回答，ProcureAgent用于虚构采购审查。它们是教学项目规格，不代表完整系统已经实现。不要为了学每种技术新建一个项目；每轮在同一项目验证一个重要问题。

| 自查问题 | 对应补课 |

不用先学完整部Python教材。已掌握基础可直接自测，具体Python机制仍需亲手验证。

## 按依赖学习与验收

| 阶段 | 章节 | 通过后能独立做什么 |
| --- | --- | --- |
| 需求与结构 | 1–4 | 写质量场景、ADR、模块边界和接口契约 |
| 数据与协作 | 5–7 | 用并发和崩溃时间线解释一致性与恢复 |
| 容量与保障 | 8–10 | 设计测量、SLO、恢复和权限验证 |

每章可分三次：先读基础并手画机制；再推演案例、修改一个条件；最后合上资料完成练习和自测。按投入时间安排，阶段通过比固定周数更重要。

## 如何避免只看懂

先写预测：哪个状态先改变、哪里可能失败、失败后是否可重试。再做一个最小实验，记录输入、预期、实际、原因。使用[工作簿](附录A-工作簿与模板.md)保存证据，下一次不看原文复述，并在一周后换条件重做。时间可按20分钟阅读、40分钟实验、20分钟讲述调整。

掌握等级：0未学；1能复述；2能独立设计并解释边界；3能实验、处理反例并迁移。不能把某项总分高视为越权或重复副作用可接受。记录个人实践和真实生产经历的区别。

## 与其他教材的关系和范围

Python教材教语言和AI应用机制；本书教如何在约束下组合、验证和演进。产品教材可用于理解业务问题，架构教材不要求先读它。完整数据库内核、编译器、共识协议证明、云平台运维和密码学是后续专项，本书提供应用架构学习闭环，不能替代全部专科学习或生产经验。

新练习成果可自建在practice/architecture_labs下；可复用实现放src，正式测试放tests。本书的SQL为设计片段，离线配套实验见工作簿，真实服务另行准备依赖和环境。

## 原理、实验和成果怎样连接

按[六组实验手册](附录D-架构实验与评审实操.md)穿插实践，不把它作为另一套日程。章节解释原因，手册安排操作，工作簿保存证据；项目API和状态契约统一引用现有项目规格。数据复制、锁与分布式边界已补充，但共识证明、数据库内核等仍需专修。

复核命令：在仓库根目录运行 `.venv\Scripts\python.exe -X utf8 scripts\verify_learning_tracks.py`；该命令检查两套新教材结构、全仓库文档链接和离线检索、事务恢复、指标成本与搜索 HTTP 实验，不运行真实云服务或客户流程。

# 章节实验区

这里保存教材S/B例子、E机制实验以及你自己构造的小变式。教材中的大任务继续使用[配套练习区](../python_ai_course/练习说明.md)，可复用业务实现放入src；实验目录不成为第二份业务实现。

## 怎样保存

按章节新建Python文件，例如`ch01_execution.py`、`ch03_copy.py`、`ch04_closure.py`。除第7章的[ch07_report](ch07_report)综合示例外，目前没有预先生成答案。每个文件先写“想验证的问题”，再写最小输入、预期与断言，最后记录一条改变条件后的结果。

从仓库根目录运行自己已经创建的脚本，例如：

```powershell
uv run python practice/chapter_labs/ch03_copy.py
```

每段教材代码通常独立运行；不要把多个同名变量的例子直接拼接后，误以为它们共享状态。需要pytest收集的T案例保存为test_开头文件，再显式指定文件路径运行。

## 建议保留的内容

- 原始预测与实际输出，以及差异原因。
- 对象关系或事件顺序的文字说明。
- 一个正常、边界或失败变式。
- 哪些结论是语言规则，哪些依赖实际版本和实现。

练完后回到[学习方法](../../docs/python-book/00-导读与学习方法.md)做验收与记录。说明文档使用中文文件名；Python模块沿用英文名称，便于命令行和项目模块组织。

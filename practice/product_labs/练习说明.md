# 产品与创业实验区

[教材](../../docs/product-founder-book/教材目录.md) · [工作簿](../../docs/product-founder-book/附录A-工作簿与模板.md)

从仓库根目录运行 `.venv\Scripts\python.exe -X utf8 practice\product_labs\metrics_and_cost.py`。

先手算20个邀请账户、8个激活、激活队列次周5个回访的比率。再运行，观察重复事件、多次行为、内部账户和窗口边界如何影响计算。成本使用虚构数据，不代表建议售价或真实经营结论。

挑战：改变价值事件、观察窗口或成本，先修改指标定义再更新断言。访谈、规格、原型和试点记录使用工作簿，区分模拟和真实证据；不向仓库提交敏感资料。

## 前后端完整路径

[全栈交付手册](../../docs/product-founder-book/附录E-全栈产品交付实操.md)配有[本地搜索样例](search_slice/server.py)。从仓库根目录运行：

```powershell
.venv\Scripts\python.exe -X utf8 practice\product_labs\search_slice\server.py
.venv\Scripts\python.exe -X utf8 practice\product_labs\search_slice\checks.py
```

第一条持续运行，浏览器打开终端显示的地址，Ctrl+C停止；第二条自动检查HTTP后退出。样例无登录、数据库或模型，使用虚构资料，仅监听本机。HTML/CSS/JS需要在浏览器实际观察；HTTP通过不等于界面或产品验证通过。

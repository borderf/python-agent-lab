# 架构实验区

[教材](../../docs/architecture-book/教材目录.md) · [工作簿](../../docs/architecture-book/附录A-工作簿与模板.md)

从仓库根目录运行 `.venv\Scripts\python.exe -X utf8 practice\architecture_labs\idempotency_sqlite.py`。

先预测同键同载荷、同键不同载荷、不同作用域和提交前失败的记录数。第二部分将本地待办与模拟远端放进两个独立的临时数据库，丢弃回执，重开连接后用原键重试。两条输出分别显示恢复前的未知结果与恢复后可核对的单一效果。

挑战：恢复时换成新键，解释效果数为什么改变；再推演远端既无幂等也无查询接口时如何对账。实验覆盖独立存储的提交顺序，真实跨进程中断、网络与并发负载在自己的服务中另做验证。

其他阶段实验按[架构实操手册](../../docs/architecture-book/附录D-架构实验与评审实操.md)推进，真实PostgreSQL实验与容量测量需自行准备隔离环境并保存结果。
